The website I made consists of a basic front end for a hackathon portal managed by a club in VIT. It is made using raw HTML,CSS and Javascript. It consists of a orange & white color scheme which is consistent for all pages in the website. I used widget-type cards for most of the text in the website because it looks clean and modern. I used SVG Icons to make the site look more professional and clean. The login button redirects the user to a login page where a dummy login can be used. (Email: admin, Password: admin123). Upon logging in, it redirects to a dashboard page with all relevant information about the hackathon and the users team. The site was made responsive mainly with CSS grid and flexbox. I used repeat(auto-fit,minmax(300px,1fr)) for the card layouts so they stack nicely on mobile.  I also added media query at 768px to adjust font sizes, make navigation links full width and simplify the hero stats. Overall, the website is simple has potential to be made into an actual hackathon portal if more time is spent designing it.
